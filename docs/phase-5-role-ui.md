# 阶段 5：双端 UI 差异

同一套页面按 `role` 微调，不复制整页代码。

## 差异一览

| 区域 | 患者端 | 管理员端 |
|------|--------|----------|
| 登录 Tab | 患者登录/注册 | 管理员登录/注册（需邀请码） |
| 设置 · 账号 | 管理员模式开关 + 邀请码 | 徽章「管理 xxx」，无开关 |
| 设置 · 档案分区 | 「我的档案」 | 「患者档案」 |
| 新手指引 | 符合条件时**自动**启动 | **不**自动启动；仍可点顶栏 `?` |
| 顶栏 | 无角色角标 | 无额外角标（身份只在设置页展示） |

## 实现要点

- `AuthContext` 暴露 `role` / `householdId` / `patientNickname`
- 自动引导：`shouldAutoStartGuide(state, { role })`，`role === "admin"` 时返回 `false`
- 顶栏角标与设置页条件渲染集中在 `App.jsx`、`SettingsPage`
- **不**复制 `TodayPage` / `InventoryPage` 等；两端功能一致

## 验收

1. 患者首次空计划 → 自动弹出引导  
2. 管理员登录同一家庭 → 不自动弹出引导；顶栏 `?` 仍可手动打开  
3. 管理员设置页为「患者档案」，头区仅徽章「管理 xxx」，无管理员模式开关/邀请码  
4. 患者设置页为「我的档案」，有管理员模式开关与邀请码  
5. 顶栏无角色角标  
6. 两端 Tab（用药计划 / 药箱 / 复诊 / 设置）功能一致，数据共享
