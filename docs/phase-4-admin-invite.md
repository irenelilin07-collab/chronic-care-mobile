# 阶段 4：管理员模式开关与邀请码

## 已实现接口

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | `/api/household/admin-mode` | 患者开启/关闭管理员模式；关闭时 `token_version++` 使管理员 JWT 失效，并给患者签发新 token |
| GET | `/api/auth/invite-code` | 查看当前未使用且未过期的邀请码 |
| POST | `/api/auth/invite-code` | 生成新邀请码（作废旧的未使用码）；需已开启管理员模式 |

## 邀请码规则

- 6 位，排除易混淆字符 `0/O/1/I/L`
- 有效期 7 天
- 一码一用；重新生成会作废未使用旧码
- 每个 household 最多 3 个管理员（注册时校验）

## 设置页（仅患者）

- Switch「允许开启管理员模式」
- 开启后：显示邀请码、过期时间、复制、生成/重新生成
- 管理员账号只显示「正在管理 xxx」+ 退出，无开关

## 验收

1. 患者开启开关 → 生成邀请码 → 复制
2. 管理员用邀请码注册 → 登录成功，看到同一份用药数据
3. 患者关闭开关 → 管理员下次请求被踢出 / 无法登录
4. 关开关后用旧邀请码注册应失败
